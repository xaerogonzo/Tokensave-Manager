The **History & worktrees** list has an **Agent** filter (all, Claude or Cursor), a **Project** filter and a **Group by project** box (on by default), because one flat table of a few hundred sessions from a dozen projects was too long to read. Rows sit under a header with a count; click a header to collapse it, and a collapsed group, your selection and the scroll position stay as you left them across the 60-second refresh. A project is the **repository**, so a worktree of it counts under it: that is read from the worktree's own `.git` file (`gitdir: <repo>/.git/worktrees/<name>`), never guessed from a folder name, and a relationship that cannot be established leaves the row in a group of its own. Two repositories that happen to share a name stay two groups, told apart by their parent folder. Cursor chats whose folder was not identified are listed together under **(folder not identified)**. The list reads the newest 200 sessions per agent (it was 50, which a quiet project would fall behind), says so when an agent reached that cap, and an unchanged transcript is not read again on a refresh. The filters are not saved between runs.
