**Release Wizard for tag-triggered releases.** If a project builds and drafts its release from a pushed tag (`.github/workflows/release.yml`) and has a `release-flow.json` at its root, the Wizard shows the detected build system (Nuitka, PyInstaller, Inno Setup) and then a four-part guide instead of the notes/build/changelog steps: a pre-flight of everything around the tip, the exact `git`/`gh` commands to tag it (with the re-tag case when a draft or an old tag is in the way, each with Copy and a Run that asks you to type the tag), a Check draft button that verifies the drafted release's files and checksums, and a manual checklist for the installer. It never publishes: you press Publish on GitHub. `release-flow.json` names the project's own check scripts, the expected release files and the checklist file; see `docs/ARCHITECTURE.md`.
