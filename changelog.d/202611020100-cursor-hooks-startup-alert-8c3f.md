### Added
- (agents) **The Manager now tells you when Cursor's tokensave hooks are broken, at launch and right after a tokensave upgrade.** `tokensave install --agent cursor` writes the hook paths unquoted and writes them that way again on every upgrade, and a failing `preToolUse` hook can stop Cursor's search and shell calls, but the break only showed if someone pressed Check or ran Doctor. A fourth startup check (3.5 s after launch, log-only, never a dialog) writes one line to the output log naming **Repair Cursor hooks** and where it is; it is silent when the hooks are fine and on a machine with no Cursor hooks file, and an unreadable `hooks.json` is reported rather than skipped. It repairs nothing itself, because that edits a file that controls an agent's tools. (`src/helpers/agent_integration.py`, `src/controllers/startup_checks_ctrl.py`, `src/app.py`, `tests/test_cursor_setup_repair.py`)
