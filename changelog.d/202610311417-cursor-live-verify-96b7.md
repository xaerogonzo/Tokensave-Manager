### Changed
- (agent-cli) **Cursor's row now matches a real install.** Measured live (agent 2026.10.22): the Windows installer writes to `%LOCALAPPDATA%\cursor-agent`, not `~/.local/bin`, so the Manager could not find a fresh install; the folder is only on the USER path of shells started afterwards, so it is now a search directory. Cursor reads the prompt from stdin (judged on a unique reply token, not an auth error), so `prompt_transport` is `stdin` and the 8 KB command-line budget no longer applies to it; the argv guard stays and is tested through a derived argv-only agent. `-p` alone can write files and run shell, so Cursor captured calls now pass `--mode ask` (new `read_only_args`, on by default, switchable) and `--trust` (new `trust_args`; headless otherwise stops at a prompt). (`src/helpers/agent_cli.py`, `tests/test_agent_cli.py`, `docs/AGENT_BACKENDS.md`)
