### Added
- (tasks) **The History list can be filtered by agent and project and grouped by project.** Measured on this machine: 275 sessions (200 Claude, 75 Cursor) in one flat table, which fold into 39 projects (OpenChem Studio alone is 129, most of them worktree names). New `helpers/session_groups.py` (no Tk): `project_of` gives a row a stable identity, the canonical repository root, and a label; a live worktree is grouped under its repository by reading its own `.git` file, a removed Claude worktree only while its repository is still a git root, a Cursor chat by what the resolver proved, and anything that cannot be established stays in a group of its own (a folder name is never evidence of a parent). Two repositories with one name are two groups, told apart by their parent folder, and group ids come from the root, not the label. `build_plan` filters and lays rows out flat or under count headers; `apply_plan` puts the plan in the tree without throwing away a person's place: the same structure only updates text, and a changed one keeps collapsed groups collapsed, new groups open, the selection (rows that still exist) and the scroll position. The Tasks tab gains an Agent box, a Project box and a Group by project checkbox (on by default; session-only, no config key) and a line saying what is shown. The scan reads the newest 200 sessions per agent (was 50), says when an agent reached the cap, and caches what an unchanged transcript says by (path, mtime, size). Group headers are not sessions for double-click or the right-click menu. `TasksController` gains no method. (`src/helpers/session_groups.py`, `src/helpers/claude_tasks.py`, `src/controllers/tasks_tab.py`, `tests/test_session_groups.py`)
