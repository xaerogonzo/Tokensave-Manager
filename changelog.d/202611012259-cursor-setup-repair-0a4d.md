### Added
- (agents) **The Manager can now repair the Cursor hooks `tokensave install` breaks, and keep the Claude-memory snapshots fresh.** Settings -> AI -> "Claude and Cursor setup" gains **Repair Cursor hooks...**: `tokensave install --agent cursor` writes each hook as an unquoted `<path with spaces>/tokensave.exe hook-...`, which Windows cuts at the first space (`'D:/Claude' is not recognized`), and a failing `preToolUse` on Grep/Shell can block a tool call; the installer writes it that way again on every upgrade. The button shows the exact diff to `~/.cursor/hooks.json`, asks, writes a byte-verified timestamped backup, quotes only tokensave's own commands as `& "exe" args` (the person's other hooks and the Manager's session marker are untouched), then RUNS each rewritten command through PowerShell and puts the file back if any fails, because that form is a belief about Cursor's shell and not a proven fact. A file that does not parse is refused and left as found. The check reports it as a failure with the fix named, in the Settings check and in Doctor. **Refresh snapshots...** lists which `memory-import` snapshots no longer match Claude's memory index and re-takes them after a yes; a project that has memory but no snapshot is only offered, never taken silently. Not done: Claude's own `~/.claude/settings.json` hooks are still only reported, never edited.
