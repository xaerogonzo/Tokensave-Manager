### Docs
- (github) **Pull requests now start from this repo's own form.** There was no `.github/PULL_REQUEST_TEMPLATE.md`, so a new GitHub or Cursor PR got a generic Summary / Test plan. The template is the shape used on recent PRs here: What, Verification, Not verified, plus a title hint (`feat(area):` / `fix(area):` / `docs:`). (`/.github/PULL_REQUEST_TEMPLATE.md`)
