### Added
- (cursor) **Pick a Cursor model from the CLI's own list.** Settings → Paths & Tools has a Model box (this setting had no UI before) and a *Refresh list* button that reads `agent --list-models`. Checked against the real CLI: 270 models parsed. The list is fetched only on click, never while the page builds, and by a worker the Tk thread polls rather than one that touches widgets. The status line says that listed does not mean your plan allows it, which is not hypothetical: `gpt-5.4-nano-none` is listed and your plan refused it. A pinned model that is not in the list is kept and reported, and with no usable list (signed out, CLI missing, unreadable output) it is reported as unknown, never as missing. Four fetch states are kept apart so a signed-out account is not told it has no models. (`src/helpers/cursor_models.py`, `src/dialogs/settings_paths.py`, `tests/test_cursor_models.py`, `tests/fixtures/cursor_models/`)
- (agent-cli) **A guarded way to let a headless call use tokensave's tools.** `build_print_argv(..., mcp_tools=True)` / `call_print(..., mcp_tools=True)` add Cursor's `--approve-mcps --force`, which are only ever added next to an enforced read-only mode: `--force` is "run everything", so the call is refused if the run is not read-only or the agent's row has no read-only mode (Claude's does not). Measured once on one model: with all flags set, a request to write a file and run a shell command was refused and nothing was created. No feature requests tools yet. (`src/helpers/agent_cli.py`, `tests/test_agent_cli.py`)
