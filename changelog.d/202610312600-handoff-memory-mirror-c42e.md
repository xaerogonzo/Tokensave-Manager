### Added
- (handoff) **Ledger decisions are mirrored into tokensave's decision memory.** Publishing a handoff now also writes each of its decisions to `tokensave tool record_decision`, so a session that asks tokensave "what was decided here" gets the answer without knowing the ledger exists. The ledger stays the record and the memory is a derived index. `record_decision` has no key, so nothing is remembered in a state file (which would go on saying "done" after the database was rebuilt): each decision is tagged `handoff:<id>` and checked against the memory itself, so a retry resumes where a failed run stopped instead of writing twice. A lookup that fails is `pending`, never "nothing there", because writing on a failed lookup is how a retry duplicates. A mirror that cannot run (no tokensave configured, a timeout) is a warning on a publish that still succeeded. `manager-cli handoff --action mirror` re-runs it over the whole ledger, exits non-zero while anything is pending, and is refused while handoff is off. Only `decisions` are mirrored: next steps and open questions are session material, and session markers carry no words. (`src/helpers/handoff_memory.py`, `src/cli.py`, `tests/test_handoff_memory.py`, `tests/test_cli_handoff.py`)
