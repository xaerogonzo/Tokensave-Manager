### Added
- (handoff) **A Settings switch, and a per-project opt-in from the Projects tab.** Settings -> AI has "Shared agent handoff (Claude and Cursor)": off by default, and only a literal `true` counts as on, so a hand-edited `"true"` or `1` shows as off and is saved as `false` rather than becoming a real opt-in by accident. Saving Settings writes `enable_agent_handoff` only when it is on or was already in the file, so it never adds a key to an install that never had one. A project then takes part only after right-click -> AI & docs -> "Enable agent handoff here…" (or "Stop agent handoff here…"), which asks first and says what it writes: the git-ignored `CLAUDE.local.md`, added to the clone's local exclude file before it exists, never overwriting a committed file, and a plain warning when the machine-wide switch is still off. The two switches are kept apart: the rule without the switch does nothing, and the switch without a rule changes no project. The CLI and the windows now share one definition of the command a rule names (`helpers/handoff_setup.py`), so they cannot write two different rules. The menu logic lives in `controllers/handoff_project_ctrl.py` because `projects_tab.py` was at 1,485 of the 1,500 lines where Doctor warns; the tab keeps two thin delegates. Checked in the real window: the entry is present and enabled under AI & docs, and the Settings section renders with no layout findings. (`src/dialogs/settings_ai.py`, `src/helpers/handoff_setup.py`, `src/controllers/handoff_project_ctrl.py`, `src/controllers/projects_tab.py`, `src/cli.py`, `tests/test_handoff_setup.py`, `tests/test_settings_tab.py`)

### Changed
- (drive) **`scroll` acts on the visible page and takes a fraction; new `menu_entries` step.** The old step scrolled the first canvas it found, which on Settings belonged to a page nobody was looking at. `menu_entries` lists the Projects context-menu entries matching a word, walking the cascades without popping the menu up (a popup is modal on Windows and freezes a driven run). (`src/debug_drive.py`, `scripts/drive/agent-handoff-ui.json`)
