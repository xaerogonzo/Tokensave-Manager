### Added
- (handoff) **Copy Claude's project memory to Cursor, once.** `manager-cli handoff --action memory-import` writes the memory INDEX (`~/.claude/projects/<project>/memory/MEMORY.md`) into `.cursor/rules/claude-memory.mdc`, which Cursor loads at the start of every session and which names the folder so an agent can open one note when a line is not enough. It is a snapshot, not a link: the file says when it was taken and that it can be out of date, and re-running it is the refresh. Only the index is copied, never the notes, redacted best-effort and cut on a line boundary when long. The file holds private notes and this machine's paths, so it is git-ignored through the repository's local exclude before it is written, and a tracked file or an ignore that cannot be made to hold refuses the write; the committed `tokensave.mdc` is never touched. A project with no Claude memory is a prerequisite exit, not an empty rule. `--action memory-remove` deletes it. Not gated by `enable_agent_handoff`: a named request for a copy, not a ledger write. (`src/helpers/memory_snapshot.py`, `src/cli.py`, `tests/test_memory_snapshot.py`)
