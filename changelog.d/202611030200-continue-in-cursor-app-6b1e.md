### Added
- (tasks) **"Continue in Cursor app…" in the History session menu, for the people who work in the Cursor desktop app rather than its terminal agent.** The existing handoff starts Cursor's terminal agent, and a terminal chat does not show up in the desktop app's agent list, so a handoff ended in a console window with nothing in the app. The new entry writes the same brief after the same confirmation, opens the session's folder in the Cursor app, and puts one message on the clipboard that points a new chat there at the brief; the message is also shown in the dialog so a clipboard another program is holding cannot lose it. It needs Cursor.exe, not the CLI. The old entry is renamed "Continue in Cursor (terminal)…" so the two are not confused, and Cursor rows are not offered the app option. (`src/helpers/agent_handoff.py`, `src/controllers/tasks_tab.py`, `tests/test_tasks_tab_sessions.py`)
