### Fixed
- (handoff) **A ledger entry could be lost silently when writers collided on Windows.** Creating the lock file while another process was deleting it raises `PermissionError` there, and it escaped as "could not write the ledger" - which a writer that ignores the result (a hook, a script) carried straight past. Measured: 2 of 25 runs of five processes appending eight entries each ended with 39 of 40. The error is now waited out like any held lock, and one that persists with no lock file present is still raised as a real denial. After the fix: 0 bad runs of 150. (`src/helpers/handoff_ledger.py`, `tests/test_handoff_ledger.py`)
