### Added
- (handoff) **A Cursor `sessionEnd` hook that records that a session happened, built but not installed.** `helpers/cursor_hooks.py` plans the one entry for `~/.cursor/hooks.json` and a generated script as a pure function, so the exact change can be shown before anything is written. Writing is cautious: a file that does not parse is refused untouched, a byte-verified timestamped backup is taken before any write, every other hook (including a person's own `sessionEnd`) is preserved, and the script is written before the entry that names it so there is never a hook pointing at nothing. `sessionEnd` is the only hook used because it was the only one besides `sessionStart` measured to fire in a headless run. The script passes the project folder, session id, reason, final status and transcript PATH to `handoff --action marker`, never any text; it prints nothing, always exits 0, and exits quietly when the payload or the Manager is missing. Because a machine-wide hook fires for every Cursor session, `marker` writes only for a project that has opted in (has the handoff rule) and only while handoff is on, and a refusal is the prerequisite exit rather than an error. Session markers are capped at 40 on their own so a day of automated runs cannot push a real handoff out of the ledger. Installing, the first exercise of a user-level `hooks.json`, waits on the person's yes.
