### Added
- (tasks) **Continue in Claude… (right-click a Cursor session), and worktree-aware sessions.** The handoff now goes both ways. A Cursor session is read from its own transcript (`~/.cursor/projects/<name>/agent-transcripts/<id>/<id>.jsonl`, captured from real runs, found by id because Cursor's folder-name encoding is not Claude's), briefed with the same three-part structure and opened in Claude Code in the folder it ran in, with no pinned model: the cheap one the Manager's automated calls use is not what a person continuing their work wants. A brief from each agent has its own filename, so neither overwrites the other's. **Open folder in Cursor** opens a session's folder as a workspace in the Cursor app by launching `Cursor.exe` directly (the `.cmd` shim breaks on `D:\Claude Co worker\...`), which is where Cursor's own importer lists a worktree's chats. Checked in the real window: 55 sessions, each Claude row offered only "Continue in Cursor", each Cursor row only "Continue in Claude", and a worktree whose folder was deleted correctly offered no folder. (`src/helpers/agent_handoff.py`, `src/helpers/session_context.py`, `src/helpers/cursor_ide.py`, `src/controllers/tasks_tab.py`, `tests/test_agent_handoff.py`, `tests/test_cursor_ide.py`, `tests/test_tasks_tab_sessions.py`, `tests/fixtures/cursor_transcripts/`)
