### Added
- (agents) **A check that the Claude/Cursor setup still stands, and presets for it.** The integration leans on things this project does not own, and each has already broken once. Doctor (and Settings -> AI -> "Check Claude/Cursor setup") now reports, with no model calls: whether every selected agent can run; each CLI's installed version against the version the integration was last measured against and the date (a different one is a warning that says so, an unreadable one is unknown, never a pass); whether the tokensave hooks in `~/.claude/settings.json` run in both agents (a bare spaced path fails; the args form is warned about only for `PreToolUse`, the one event measured to break Cursor's shell calls); and whether the Cursor session-end hook agrees with the handoff switch. Silent in Doctor when everything passes. Nothing is repaired: a fix is named, and anything that edits an agent's config stays a reviewed diff. **Presets** ("Claude only" = how it worked before Cursor; "Claude and Cursor" = handoff on) show exactly which settings they would change and apply them to the FORM, so nothing is saved until Settings is, and one can be abandoned by closing without saving. The current preset is derived from the values each time and never stored, so changing one switch just makes it "Custom". Every behaviour keeps its own setting.
- (agents) **Agents the Manager starts no longer inherit a Git Bash environment on Windows.** `SHELL`, `MSYSTEM` and `BASH*` are removed from the environment of every agent CLI it launches. Measured: a Manager started from Git Bash made Cursor evaluate its PowerShell hook wrapper in bash, so every shell call was refused with "Hook blocked ... syntax error", which reads exactly like a broken hook.
