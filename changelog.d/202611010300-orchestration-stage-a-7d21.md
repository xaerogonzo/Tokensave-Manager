### Added
- (orchestration) **Hand a task to Claude or Cursor, in its own copy.** Settings -> AI -> "Delegated agent tasks" (off by default; only a literal `true` counts, enforced at the one launch path and not just on the button) enables the Tasks tab's new "Agent tasks" view. "New task" shows WHERE the agent will work (a separate worktree next to the project under `_scratch`, on its own `tsm/<id>` branch), WHAT it may do (edit files; no shell), and why a launch is refused when it is: uncommitted tracked changes (named), a limit (named), an agent with no measured write mode, a disk it could not measure. The agent runs headless with its prompt on stdin; the Manager records the pid with the process start time before anything else can fail, measures the diff with git (never the agent's own account), and reads back the session id and the usage the agent REPORTED, labelled, never converted to money. A task that exits non-zero or reports an error is `failed` and keeps its diff; only a clean, measured one is `result_ready`. Cancel kills the whole process tree (a plain kill left seven descendants running). A task recorded as running whose process is gone is `lost`, proven by pid AND start time, never guessed. **Accept records that you want the result and merges nothing**; the branch is merged from the Git tab. Reject records that you do not. "Discard copy" removes the worktree and keeps the branch. Quitting with a task running asks, then stops every task and lets each record how it ended. Claude is given tokensave through `--strict-mcp-config` with one config file naming one server (measured: without it a user-scope entry can serve the wrong project); Cursor through a `.cursor/mcp.json` the Manager writes in the worktree and leaves out of the measured diff. Run live against both real agents on a scratch repo: both reached `result_ready` with the right file, a session id and usage, and the project checkout stayed clean. New config: `enable_agent_orchestration`, optional `orchestration_limits`. ### Fixed

Only a file named like a record (`t` and twelve hex digits) is read now, and a genuinely damaged record is still counted. Found by the first person to use the view.
